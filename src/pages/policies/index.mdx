# Policies and support

Course-level practice, in one place so that assessment briefs can link here
rather than each restating it. Where this page is silent, the university's own
rules apply unchanged — this page does not override them.

## Late work and extensions

Extensions are arranged before the due date wherever that is possible. If
something has already gone wrong, ask anyway; a late request is better than a
silent non-submission.

## Academic integrity

The work you submit must be yours, and any assistance must be declared. That
includes generative tools.

## Generative tools

This course is about defending a design, and a defence you cannot explain is
not a defence. You may use generative tools; you must be able to account for
every technical claim in your submission, and you must say where the tool was
used.

The same standard the course applies to itself applies to you: a number is
either sourced, or it is labelled as a course-defined boundary, or it is
labelled synthetic. Fabricated precision is treated as an integrity problem,
not a stylistic one.

## Evidence conventions on this site

Two labels appear throughout, and they are not the same kind of claim:

- **Course-defined** — a boundary this course chose, such as the 12% threshold.
  It is a modelling decision, not a measurement.
- **Synthetic trace** — a property of the generated teaching trace. Not an
  observation of any real system.

No page on this site presents a figure from a real electricity system.

## Getting help

Bring difficulties to the studio, which is the part of the week designed for
them.
